# Analysis pipeline
Analysis of the network irreversibility proceeds according to the following procedure: 

## Preparation: Generating the rules and finding attractors
### Convert RegulonDB network to GraphML file
Run the command `python read_reduce_grn.py`. This will create the file `networks/rs2.gml`.

### Generate networks
Run the command `./generate_nets.sh`.
This will generate network files in the `netfiles/` directory.
There should be 20 for each value of $r$ and $s$ considered in the manuscript (except those that lead to unique rules). 

### Find attractors
Run the command `./bns.sh`.
This will generate the attractors, which are stored in the `attfiles/` directory.

Run the command `./attcsv.sh`.
This will generate the files that contain the first states of the attractors, which will be used to detect irreversibility.

## Execution: detecting irreversibility and characterizing transitions
### Run the irreversibility detection algorithm

#### Parallelizing instances with large numbers of attractors
Run the command `./simulation2.sh`.

This command runs the script `try_KO_pre_chunked.r`, which executes a version of the irreversibility detection algorithm. It is designed to use all available processes on the computer.
Full recalculation of the results takes approximately 3,000 hours on a single processor.
Therefore, it is recommended to take advantage of a computing cluster. 
The maximum number of processes can be controlled by altering line 4 (starting with `cpus`) to be equal to the desired maximum number of processes.
Use of the `wait -n` command on line 8 (inside the function pwait) requires bash version $\geq 3.4$. 
If using an older version of bash, change the line to `sleep 1`.

The script `./simulation2.sh` contains a list of the instances with the largest number of attractors. By splitting up the calculations of each instance over many processors, this script expedites the calculation of irreversibility. After the results are generated, the results must be recombined using `./gather_chunked_files.py`.

#### Run the algorithm on the remaining cases
Run the command `./simulation.sh`.

This command runs the script `try_KO_pre.r`, which executes the irreversibility detection algorithm. It is designed to use all available processes on the computer. 
The script's default behavior is to skip any files that have been previously completed---including those that are calculated by the `./simulation2.sh` script.
If recalculation of existing files is needed, they will need to first be removed from the `logging/` directory.



### Get _crp_ irreversibility response genes
Run the command `./top_irr_resp_gns.sh`.

This command runs the R script `analyze_topKO_irr_resp_gns.r`, which obtains the irreversible response genes for each transition.
The options described for the script `simulation.sh` apply (see preceding section). 

### Analyze the attractor transitions
Run the command `./attr_trans.sh`.

This command runs the R script `analyze_attractor_transitions.r`, which characterizes the starting and ending attractors for each transition.
The options described for the script `simulation.sh` apply (see two sections above).

### Finding reversible and irreversible genes
Run the command `./find_rev_genes.sh`.

This command runs the script `find_rev_genes.r`, which calculates the lists of genes that are reversible and irreversible for each perturbation. It also calculates the stable attractor reached after the first perturbation.

### Finding basin sizes
Run the command `./BasinSize.sh`.

This command runs the script `BasinSize.r`, which estimates the basin size of the attractor by sampling random initial conditions. These frequencies are stored in the `basinFreqs-*.tsv` files in the `basins/` directory. The outputs are used in the `irr_prob.ipynb` notebook.


## Presentation: calculating statistics and generating figures
### Figure S2
Generation of Fig. S2 requires the creation of `tmp/overall_output_d.pkl`, which stores summary statistics for independent rules ensembles.
This file can be generated by running `analyze_replicates.py`.

### Figures 4–7 and Figures. S1-S4
Figures 4–7 and Figures S1-S4 can be generated by running the cells in `irr_prob.ipynb`. This script also can generate Fig. S2 if the file `tmp/overall_output_d.pkl` has been generated by `analyze_replicates.py`.

### Figure 8B
Figure 8B and the associated statistics can be generated by running the cells in `case_study.ipynb`.

### Figure S6
The calculations supporting Fig. S6 are performed in `attractor_weighted_irreversibility.ipynb`. 
The results generated in the paper correspond to those generated by running `python attractor_weighted_irreversibility.py M`, which uses the median expression of each gene to binarize expression. In addition, this notebook relies upon the expression data `all_logtpm_dat.pkl`, the associated metadata `ecoli_metadata.pkl`, and the binarization thresholds `gsym_thr_ser.pkl`. These three files can be downloaded from the `DataDownloader.py` script, which retrieves them from a public Google Drive folder.

### Figure S7
The this figure illustrates the output of the differential equation analysis performed in `diffeq_analysis.ipynb`.


### SI attractor statistics
The percentages of preserved attractors and attractor pairs in transitions may be calculated from `attractor_diff.ipynb`.
